# Conventions

The full formalism `cvcircuit` implements, in one place. Every symbol here
is exactly what appears in the code. Primary references: Brask,
[arXiv:2102.05748](https://arxiv.org/abs/2102.05748) ("Gaussian states and
operations — a quick reference"); Weedbrook, Pirandola, García-Patrón,
Cerf, Ralph, Shapiro & Lloyd, [Rev. Mod. Phys. **84**, 621
(2012)](https://arxiv.org/abs/1110.3234); Ferraro, Olivares & Paris,
[arXiv:quant-ph/0503237](https://arxiv.org/abs/quant-ph/0503237); Banchi,
Braunstein & Pirandola, [PRL **115**, 260501
(2015)](https://arxiv.org/abs/1507.01941) (fidelity).

## Quadratures and ħ

$$
\hat{x}_k = \sqrt{\tfrac{\hbar}{2}}(\hat a_k + \hat a_k^\dagger), \qquad
\hat{p}_k = -i\sqrt{\tfrac{\hbar}{2}}(\hat a_k - \hat a_k^\dagger), \qquad
[\hat x_j, \hat p_k] = i\hbar\,\delta_{jk}
$$

`hbar` is a keyword on every state and circuit constructor, **default 2**
(vacuum covariance = 𝟙, i.e. *shot-noise units*, matching TheWalrus /
Strawberry Fields / most CV-QKD papers). Pass `hbar=1` for the
Brask/Ferraro-Olivares-Paris convention used in much of the theory
literature (vacuum covariance = ½𝟙).

Your own experimental pipeline (`qopt/tomography.py`'s `# Normalize traces
to 0.5 vacuum variance`, and the analytic Wigner functions in `cvqubits`)
is `hbar=1` — pass `hbar=1` when comparing against homodyne data normalized
that way.

Complex amplitude: $\alpha = (x+ip)/\sqrt{2\hbar}$, so a displacement by
$\alpha$ shifts the mean by $d=\sqrt{2\hbar}\,(\mathrm{Re}\,\alpha,\ \mathrm{Im}\,\alpha)$.

## Ordering

Phase-space vectors and covariance matrices are stored in **xpxp**
(interleaved) order:

$$ \hat{\mathbf r} = (\hat x_1, \hat p_1, \hat x_2, \hat p_2, \ldots, \hat x_n, \hat p_n)^T $$

so each mode is a contiguous 2×2 block — partial traces, mode embeddings
and per-mode slicing are all plain array slices. Strawberry Fields,
TheWalrus and the Banchi-Braunstein-Pirandola paper use **xxpp**
(block) order, $(\hat x_1,\ldots,\hat x_n,\hat p_1,\ldots,\hat p_n)^T$;
`conversions.xpxp_to_xxpp()` / `xxpp_to_xpxp()` convert vectors or
matrices at the boundary, and `GaussianState.to_xxpp()` /
`GaussianState.from_xxpp()` do the same for a whole state.

## Symplectic form and covariance matrix

$$
\boldsymbol\Omega = \bigoplus_{k=1}^n \begin{pmatrix}0&1\\-1&0\end{pmatrix}, \qquad
[\hat r_j,\hat r_k] = i\hbar\,\Omega_{jk}
$$

$$
\sigma_{jk} = \tfrac12\langle\{\Delta\hat r_j,\Delta\hat r_k\}\rangle, \qquad
\sigma_{\rm vac} = \tfrac{\hbar}{2}\mathbb 1, \qquad
\sigma + \tfrac{i\hbar}{2}\Omega \succeq 0
$$

The last inequality is the uncertainty principle; `GaussianState.__init__`
checks it (minimum eigenvalue ≥ −1e-8) and raises `ValueError` — with a
reminder to check `hbar` — if it fails. Note `Omega` itself does **not**
carry a factor of ħ (`ops.symplectic_form`); ħ only enters through
`sigma_vac` and the displacement map.

## Wigner function

$$
W(\mathbf r) = \frac{\exp\!\left[-\tfrac12(\mathbf r-\bar{\mathbf r})^T\sigma^{-1}(\mathbf r-\bar{\mathbf r})\right]}{(2\pi)^n\sqrt{\det\sigma}}
$$

`GaussianState.quasiprobability(x, p, s, mode)` generalizes this to the
full family of $s$-ordered quasiprobability distributions via
$\sigma_s = \sigma - s\,\tfrac{\hbar}{2}\mathbb 1$: $s=0$ is the Wigner
function, $s=-1$ the Husimi $Q$ function ($\sigma_Q=\sigma+\tfrac\hbar2\mathbb1$,
always a valid probability distribution — it's $W$ convolved with vacuum
noise), $s=+1$ the Glauber-Sudarshan $P$ function ($\sigma_P=\sigma-\tfrac\hbar2\mathbb1$,
only a genuine function when that's positive semi-definite, i.e. the state
is *classical* in Mandel's sense — `p_function()` raises `ValueError`
otherwise, and `is_classical()` checks the condition directly).

## Rotation sign

$$ R(\varphi) = \begin{pmatrix}\cos\varphi & -\sin\varphi\\ \sin\varphi & \cos\varphi\end{pmatrix}, \qquad \hat a \to \hat a\,e^{i\varphi} $$

This is the *active*, thewalrus-style convention (â picks up a positive
phase). Brask's note uses the opposite sign — flip `phi -> -phi` when
cross-referencing it.

## Symplectic matrices for every unitary op

All hbar-independent (only *displacement*, below, depends on ħ); every one
of these is `ops.<name>` and also a `GaussianState`/`Circuit` method of the
same name.

| op | symplectic matrix | notes |
|---|---|---|
| `displacement(alpha, hbar)` | — (shifts mean by $d$) | $d=\sqrt{2\hbar}(\mathrm{Re}\,\alpha,\mathrm{Im}\,\alpha)$ |
| `rotation(phi)` | $R(\varphi)$ above | |
| `squeezing(r, phi)` | $\cosh r\,\mathbb 1_2 - \sinh r\,\Sigma_\varphi$ | $\Sigma_\varphi=\begin{pmatrix}\cos\varphi&\sin\varphi\\\sin\varphi&-\cos\varphi\end{pmatrix}$; at $\varphi=0$: $\mathrm{diag}(e^{-r},e^{r})$ |
| `shear(s)` | $\begin{pmatrix}1&0\\s&1\end{pmatrix}$ | $p\to p+sx$, generated by $x^2$ |
| `fourier()` | $R(\pi/2)$ | |
| `two_mode_squeezing(r, phi)` | $\begin{pmatrix}\cosh r\,\mathbb1_2 & \sinh r\,\Sigma_\varphi\\\sinh r\,\Sigma_\varphi & \cosh r\,\mathbb1_2\end{pmatrix}$ | entangles a fresh mode pair |
| `beamsplitter(theta, phi)` | $\begin{pmatrix}\cos\theta\,\mathbb1_2 & -\sin\theta\,R_\varphi^T\\\sin\theta\,R_\varphi & \cos\theta\,\mathbb1_2\end{pmatrix}$ | transmittance $T=\cos^2\theta$ of mode 1; `beamsplitter_t(T, phi)` takes $T$ directly |
| `cz(s)` | $p_1\to p_1+sx_2,\ p_2\to p_2+sx_1$ | generated by $x_1x_2$; CV cluster-state edge |
| `cx(s)` | $x_2\to x_2+sx_1,\ p_1\to p_1-sp_2$ | CV SUM/QND gate |
| `interferometer(U)` | block $(j,k)=\begin{pmatrix}\mathrm{Re}\,U_{jk}&-\mathrm{Im}\,U_{jk}\\\mathrm{Im}\,U_{jk}&\mathrm{Re}\,U_{jk}\end{pmatrix}$ | passive $n$-mode unitary $U$ |

These match `lcg_plus/operations/symplectic.py`'s conventions exactly
(same $\hbar=2$, xpxp, same signs), so results are directly cross-checkable
between the two libraries — this is deliberate, not incidental.

## Channels

A Gaussian channel is $(X, Y, d)$: $\bar{\mathbf r}\to X\bar{\mathbf r}+d$,
$\sigma \to X\sigma X^T+Y$, with complete positivity requiring
$Y+\tfrac{i\hbar}{2}(\Omega-X\Omega X^T)\succeq0$ (checked by
`GaussianChannel.__init__`).

| channel | $X$ | $Y$ |
|---|---|---|
| `loss(eta, nbar_env)` | $\sqrt\eta\,\mathbb1$ | $(1-\eta)\tfrac\hbar2(2\bar n_{\rm env}+1)\mathbb1$ |
| `amplifier(g, nbar_env)` | $\sqrt g\,\mathbb1$ | $(g-1)\tfrac\hbar2(2\bar n_{\rm env}+1)\mathbb1$ |
| `excess_noise(xi)` | $\mathbb1$ | $\xi\tfrac\hbar2\mathbb1$, $\xi$ in shot-noise units |

**Phase noise is deliberately not a `GaussianChannel`.** Averaging a
Gaussian state over $\varphi\sim\mathcal N(\bar\varphi,\sigma^2)$ produces a
genuinely non-Gaussian mixture of rotated Gaussians whenever the state is
displaced or anisotropically squeezed, and the map depends on the state's
own mean — it has no fixed $(X,Y)$. `channels.phase_noise` instead
computes the **exact** first and second moments of the true output state,

$$
\mathbb E[R(\varphi)] = e^{-\sigma^2/2}R(\bar\varphi), \qquad
\mathbb E[R(\varphi)MR(\varphi)^T] = \tfrac12\mathrm{tr}(M)\mathbb 1 + e^{-2\sigma^2}R(\bar\varphi)M_0R(\bar\varphi)^T
$$

for symmetric $2\times2$ $M$ with traceless part $M_0$, and returns the
Gaussian state with those moments — the same "Gaussian-equivalent
phase noise" approximation used throughout the CV-QKD literature (e.g.
Lodewyck et al., PRA **76**, 042305 (2007)), made explicit instead of
silently assumed.

## Measurements

General-dyne is the single primitive. Blocking $\sigma=\begin{pmatrix}A&C\\C^T&B\end{pmatrix}$
over (kept | measured) and measuring against a Gaussian POVM of covariance
$\sigma_M$:

$$
\text{outcome}\ \mathbf u \sim \mathcal N(\bar{\mathbf r}_B,\ B+\sigma_M), \qquad
\sigma_A' = A - C(B+\sigma_M)^{-1}C^T, \qquad
\bar{\mathbf r}_A' = \bar{\mathbf r}_A + C(B+\sigma_M)^{-1}(\mathbf u - \bar{\mathbf r}_B)
$$

**Heterodyne** is general-dyne with $\sigma_M=\tfrac\hbar2\mathbb1$ (a
vacuum-noise POVM); the outcome is converted to a complex amplitude.
**Homodyne** is implemented as its own exact rank-1 update (not a
$\sigma_M\to0$ limit, which is numerically singular): rotate the mode by
$-\theta$, then with $\Pi=\mathrm{diag}(1,0)$ and $\mathbf u=(u,0)$,

$$
\sigma_A' = A - \tfrac1{B_{11}}C\Pi C^T, \qquad
\bar{\mathbf r}_A' = \bar{\mathbf r}_A - \tfrac1{B_{11}}C\Pi(\bar{\mathbf r}_B-\mathbf u)
$$

Measured modes are **reset to vacuum and kept in place** — mode indices
never shift (`GaussianState.reduced()` drops them if you don't want them).

## Squeezing in decibels

$$ r_{\rm dB} = 10\log_{10}\!\big(e^{-2r}\big) $$

so squeezing ($r>0$) is reported as **negative** dB — `conversions.r_to_db(1.0)`
= −8.686 dB — matching `lcg_plus.conversions` and everyday lab usage ("−3 dB
of squeezing"). Some references (e.g. `TN_Sampling`) use the opposite sign;
double-check when comparing numbers from elsewhere.

## Fidelity

`quantum_info.fidelity` returns the **squared** overlap — for two coherent
states, `fidelity(coherent(a), coherent(b)) == exp(-abs(a - b)**2)` — matching
`qcircsim.quantum_info.state_fidelity`'s convention (and Nielsen & Chuang's
$F(\rho,\sigma)=\big(\mathrm{Tr}\sqrt{\sqrt\rho\,\sigma\sqrt\rho}\big)^2$, sometimes
called the "Jozsa" convention; note some papers, including Banchi-Braunstein-Pirandola
itself, call the *unsquared* overlap "fidelity" instead). Computed via the
Banchi-Braunstein-Pirandola formula for arbitrary multimode Gaussian
states, rescaled to $\hbar=1$ internally (the formula's own convention);
since $\Omega$ transforms the same way as $\sigma$ under any fixed
reordering, it's applied directly in this library's native xpxp order with
no xxpp conversion needed.

## Entanglement, separability and steering

All entropies/entanglement measures work in **shot-noise units**,
$\bar\nu_k = 2\nu_k/\hbar$ (vacuum = 1), with a `base` parameter (default 2,
bits).

* **Von Neumann entropy**: $S=\sum_k g(\bar\nu_k)$,
  $g(x)=\tfrac{x+1}2\log_2\tfrac{x+1}2-\tfrac{x-1}2\log_2\tfrac{x-1}2$.
* **Rényi-$\alpha$**: closed form via the same $\bar\nu_k$; $\alpha=2$
  reduces to $-\log_2(\text{purity})$.
* **Logarithmic negativity**: $E_N=\sum_k\max(0,-\log_2\tilde\nu_k)$, the
  $\tilde\nu_k$ being the symplectic eigenvalues of the partially
  transposed (one side's $p\to-p$) covariance matrix (Vidal & Werner, PRA
  **65**, 032314 (2002)).
* **Separability (PPT/Simon)**: $E_N=0$ is necessary for separability of
  any bipartition, and *also sufficient* for a 1×N split (Simon, PRL **84**,
  2726 (2000); Werner & Wolf, PRA **64**, 021802(R) (2001)) — for larger
  splits a positive result is only the necessary PPT test.
* **Duan et al.** (PRL **84**, 2722 (2000)): $\mathrm{Var}(x_1-x_2)+\mathrm{Var}(p_1+p_2)<2\hbar$
  is a sufficient (not necessary) inseparability witness for a mode pair.
* **Gaussian steering** (Kogias, Lee, Ragy & Adesso, PRL **114**, 060403
  (2015)): $G^{A\to B}=\sum_{k:\,\nu_k<1}-\log\nu_k$ over the symplectic
  eigenvalues of the Schur complement $\sigma_{B|A}=\sigma_B-\sigma_{AB}^T\sigma_A^{-1}\sigma_{AB}$
  — the same conditioning formula the general-dyne measurement update
  uses, in the $\sigma_M\to0$ limit.
* **Entanglement of formation / discord**: implemented only for **pure**
  global states, where both exactly equal the reduced-state entropy (a
  general fact for any pure bipartite state) — the well-defined,
  exactly-computable case. Mixed-state EoF needs a convex-roof
  optimization and mixed-state Gaussian discord needs a further closed
  form (Giorda & Paris, PRL **105**, 020503 (2010); Adesso & Datta, PRL
  **105**, 030501 (2010)) that this package doesn't implement; use
  `logarithmic_negativity`/`negativity` for mixed states instead.

## Interferometer decomposition

Two ways to decompose an $n$-mode unitary into a physical mesh of
beamsplitters and phase shifters; both return the same
`("phase", mode, angle)` / `("bs", mode1, mode2, theta, phi)` element list
(interchangeably), with `theta, phi` exactly `ops.beamsplitter`'s arguments:

* `decompositions.clements_decomposition` — the depth-optimal
  **rectangular** mesh (Clements, Humphreys, Metcalf, Kolthammer &
  Walmsley, Optica **3**, 1460 (2016)), circuit depth $n$ — the standard
  choice in integrated/fibre photonics, and this package's **recommended
  default**.
* `decompositions.interferometer_mesh` — the simpler **triangular** mesh
  (Reck et al., PRL **73**, 58 (1994)), circuit depth $2n-3$.

Both are exact and general. Clements' algorithm alternates nulling matrix
elements via left multiplication (combining two rows) and right
multiplication by the *inverse* T-matrix (combining two columns) along
successive anti-diagonals, then uses a phase-screen "move" identity,

$$
T^{-1}(\theta,\varphi)\,D = D\,T(\theta,\varphi'), \qquad
\varphi' = \varphi + \delta_{m_1} - \delta_{m_2} + \pi
$$

($D=\mathrm{diag}(e^{i\delta_1},\ldots,e^{i\delta_n})$ **unchanged** — only
$\varphi$ shifts) to sweep the diagonal phase matrix through every
row-eliminated element, reassembling the mixed left/right eliminations
into one physical left-to-right mesh followed by a single output phase
screen. This identity is this package's own re-derivation for
`ops.beamsplitter`'s T-matrix convention (verified against it directly,
`tests/test_decompositions.py::test_clements_is_shallower_than_reck`) —
the source paper uses a different convention, so its version of the
identity doesn't transfer directly.
